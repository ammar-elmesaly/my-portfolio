## Local Development

### Prerequisites

- Node.js 20+
- npm, pnpm, yarn, or bun

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open <http://localhost:3000> in your browser.

### Production build

```bash
npm run build
npm run start
```

## Deployment

This portfolio is designed for modern hosting platforms such as Vercel, Netlify, or any Node-compatible deployment environment. For a quick deployment flow, Vercel is the most straightforward option given the Next.js setup.
